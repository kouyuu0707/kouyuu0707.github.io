# kouyuu0707.github.io

GitHub Pages向けのポートフォリオです。HTML・CSS・JavaScriptで構成し、ビルドは不要です。

```text
.
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── main.js
```

## 確認

`index.html` をブラウザで開いて確認できます。

## 編集

- `index.html`：名前、紹介文、制作物、GitHubリンク
- `assets/css/style.css`：配色、余白、レスポンシブレイアウト
- `assets/js/main.js`：表示中のセクションに合わせたナビゲーションの強調

制作物は種類で分類せず、ひとつの一覧に掲載します。完成した作品と制作途中の作品を並べられます。
各作品の進捗は `work-status` の文言とクラス（完成：`status-complete`、制作中：`status-progress`）で指定します。

制作中の作品として「bom's tag」「伊能忠敬ゲーム」を掲載しています。画像は仮のイメージです。
Google Fontsが利用できない環境ではシステムのフォントで表示されます。

## GitHub Pages

変更をGitHubへ反映し、リポジトリの Settings → Pages で対象ブランチのルート `/` を公開元に指定します。

## 自然の演出

背景はCSSで森と木漏れ日を表現しています。葉は不規則な間隔で舞い、端末の「動きを減らす」設定では非表示になります。
Web Audioで風の合成音を連続再生し、ときどきセミの合成音を加えます。自動再生が制限されるブラウザでは、最初のクリック・タップ・キー操作で開始します。別のタブに移ると一時停止します。
